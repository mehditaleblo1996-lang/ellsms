ارسال خودکار پیامک به مشتری هنگام تغییر وضعیت سفارش، از طریق پنل پیامک ELLSMS.

== Description ==

* یک متن جداگانه برای هر وضعیت سفارش (از جمله وضعیت‌های سفارشی)، با متغیرهایی مثل {first_name}، {order_number} و {total}.
* ارسال در پس‌زمینه با Action Scheduler ووکامرس؛ ثبت سفارش هیچ‌وقت کند نمی‌شود.
* پیامک هر وضعیت برای هر سفارش حداکثر یک بار ارسال می‌شود؛ نتیجه در یادداشت‌های سفارش ثبت می‌شود.
* ارسال دوباره از کادر «عملیات سفارش».
* سازگار با HPOS (جدول‌های سفارش جدید ووکامرس).

== Installation ==

1. افزونه را از «افزونه‌ها ← افزودن ← بارگذاری افزونه» نصب و فعال کنید.
2. در پنل ELLSMS یک کلید API با دسترسی messages:send و balance:read بسازید.
3. ووکامرس ← پیامک ELLSMS: آدرس پنل و کلید را وارد و «آزمایش اتصال» را بزنید.
4. برای وضعیت‌های دلخواه تیک «فعال» را بزنید و متن را ویرایش کنید.

راهنمای کامل: docs/integrations-guide.md در مخزن ELLSMS، یا صفحه‌ی «یکپارچه‌سازی‌ها» در پنل.
